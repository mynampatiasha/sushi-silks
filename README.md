# Sushi Silks

Landing page for Sushi Silks, a women-owned saree and ethnic-wear store in
Kasturi Nagar, Bengaluru — sarees, cotton salwar sets, kurtas, and dupattas.

## Tech stack

Static HTML, CSS, and vanilla JavaScript — no build step, no framework.

## Structure

- `index.html` — the page
- `style.css` — styles
- `script.js` — page behavior
- product photos

## Running locally

```bash
python -m http.server 8000
```
